# 🧰 MX Angular Web Toolkit (Frontend Acceleration Utilities)

[![Angular](https://img.shields.io/badge/Angular-v17%2B-DD0031?style=flat-square&logo=angular&logoColor=white)](https://angular.io)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.x-3178C6?style=flat-square&logo=typescript&logoColor=white)](https://www.typescriptlang.org)

A collection of lightweight TypeScript utilities, standalone directives, and custom RxJS pipes built to accelerate frontend development in Angular applications.

---

## 📦 What's Inside

- 🎯 **DOM Directives:** Click outside listener, autofocus helpers, debounce input handler.
- 🔄 **Pipes:** Safe HTML sanitizer, localized currency formatter, text truncation with tooltip support.
- ⚡ **Signals & RxJS Helpers:** Convenient state transformation operators.
